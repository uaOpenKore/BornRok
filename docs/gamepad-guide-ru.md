# Управление с геймпада

Клиент поддерживает полноценную игру с геймпада (Xbox, PlayStation 4, Nintendo Switch, Steam Deck и совместимые). Кнопки привязаны по ПОЗИЦИИ, поэтому раскладка одинакова на всех контроллерах — на экране рисуются глифы именно вашего геймпада. Ниже A/B/X/Y = нижняя/правая/левая/верхняя лицевые кнопки (на PS — ✕/○/□/△).

## Вход и выход из режима геймпада

- Если геймпад подключён при запуске — клиент **сам** входит в режим геймпада.
- Если геймпад подключили во время игры — появится окно **«Switch to gamepad control mode?»** (A — да, B — нет).
- Выйти из режима: вручную через **Settings → General → Control: Keyboard/Gamepad**, либо режим выключится сам, когда отключены все геймпады.
- Мышь и клавиатура продолжают работать в режиме геймпада (удобно для чата).

Снизу экрана показывается строка активных режимов (например `Standard · Camera · Cam Lock`). В ней же виден статус привязки камеры — `Cam Lock` (следует за чаром) или `Cam Free` (свободная).

## Режимы (переключение — крестовина D-pad)

Крестовина переключает базовый режим; повторное нажатие того же направления возвращает в **Стандартный**:

- **D-pad ↑** — режим Меню
- **D-pad ↓** — наведение на мобов
- **D-pad ←** — наведение на НПЦ
- **D-pad →** — наведение на игроков
- **L3 (клик левого стика)** — режим Мыши (курсор)
- **R3 (клик правого стика)** — режим Камеры

Режимы Мыши/Камеры и панели скиллов — накладываются поверх и могут работать вместе.

## Стандартный режим (перемещение и бой)

**Движение (танковое):**
- Левый стик вперёд/назад — идти по направлению взгляда; назад — пятиться, не разворачиваясь.
- Левый стик влево/вправо — стрейф (скольжение вбок, лицо не крутится).
- Правый стик влево/вправо — поворот чара на 45°.
- Правый стик вверх/вниз — наклон камеры.

**Лицевые кнопки (без зажатого плеча):**
- A (низ) — атаковать ближайшую цель.
- Y (верх) — сесть/встать.
- X (лево) — вкл/выкл автоатаку.
- B (право) — подобрать предмет.

## Камера

- По умолчанию камера привязана за спиной чара (при включённом Camera Lock следует за поворотами). При входе в режим геймпада Camera Lock включается автоматически.
- **R3** включает режим Камеры: правый стик вращает камеру вокруг чара (работает и при включённом Camera Lock), вверх/вниз — зум.
- **Back (View / Share / Select)** — переключает Camera Lock вкл/выкл. Статус (`Cam Lock` / `Cam Free`) виден в нижней строке режимов.
- При выключенном Camera Lock движение/повороты камеру не двигают — она остаётся там, куда вы её отвели.

## Режимы наведения (мобы / НПЦ / игроки)

Выбранная цель обведена розовой рамкой.

- B (право) — выбрать ближайшую цель нужного типа.
- Правый стик — выбор цели по направлению относительно текущей.
- A (низ) — действие по цели (атака моба / заговорить с НПЦ).
- X (лево) — контекст-меню (на игроке: сделка/чат/друг).
- Y (верх) — сбросить контекст-меню; если меню нет — следующая цель.

Камера сама центрируется на выбранной цели.

## Панель быстрого доступа (скиллы и итемы)

В режиме геймпада панель — 2 ряда по 8 слотов (4 — отступ — 4 = 4 блока по 4). На слотах нарисованы кнопки вашего геймпада.

**Зажмите плечо → лицевые кнопки бьют по слотам этого блока:**
- L2 — ряд 1, блок 1  R2 — ряд 1, блок 2
- L1 — ряд 2, блок 1  R1 — ряд 2, блок 2
- Внутри блока: A=слот 1, B=слот 2, X=слот 3, Y=слот 4.

**Назначение слота:** контекст-меню на скилле/итеме → «Слот» → выберите закладку группы и слот.

## Режим меню (навигация по окнам)

Открывается **D-pad ↑** или кнопкой **Start (≡)** (Start открывает ESC-меню и включает режим меню). Сфокусированный элемент обведён розовой рамкой.

- Вход в меню-режим наводит фокус на кнопку «Статус» в главном меню.
- Правый стик — перемещение фокуса между элементами.
- A (низ) — выбрать/нажать (открыть окно).
- Y (верх) — закрыть окно.
- X (лево) — назад.
- B (право) — контекст-меню элемента.
- Левый стик — двигать окно по экрану.
- L1/R1 — вкладки внутри окна.
- L2/R2 — переключение между открытыми окнами.

## Курсор

- Режим Мыши (L3): левый стик управляет курсором. A=ЛКМ, X=ПКМ.
- PS4: тачпад управляет курсором в любом режиме (нажатие тачпада = ЛКМ).
- Steam Deck: левый трекпад — курсор, правый трекпад — камера.

## Ввод текста (экранная клавиатура)

Когда в режиме геймпада сфокусировано текстовое поле (логин аккаунт/пароль, внутриигровой чат), снизу появляется экранная QWERTY:

- **Крестовина** — двигать подсветку, **A** — нажать клавишу.
- **X** — Shift (следующая буква заглавная), **B** — пробел, **Y** — backspace.
- Клавиша **123 / abc** — переключить страницу символов/цифр, **OK** — Enter (отправить / подтвердить).
- На логине **Start** переключает поля аккаунт/пароль.

Пока клавиатура открыта, она держит пад — крестовина/лицевые кнопки набирают текст, а не управляют игрой.

## Количество предмета (выброс / перемещение)

При выбросе или перемещении стопки появляется окно количества:

- **Крестовина влево / вниз** — уменьшить, **крестовина вправо / вверх** — увеличить.
- **A** — ОК, **Y** — отмена.

## Логин и выбор персонажа

С одним геймпадом можно полностью зайти в игру:

- **Логин:** крестовина выбирает сервер, **A / Start** — далее, **B** — выход; аккаунт и пароль набираются экранной клавиатурой.
- **Выбор персонажа:** крестовина влево/вправо по слотам, **A** — войти в игру (или открыть создание на пустом слоте), **X** — удалить, **B / Start** — назад. Новый персонаж создаётся со сбалансированными статами 5/5/5.

## GamePad Setup (инверсия осей стика)

Некоторые контроллеры (особенно в режиме DirectInput) сообщают ось стика перевёрнутой. Откройте **ESC → GamePad Setup** и включите инверсию по нужной оси:

- Левый стик — Invert X / Invert Y
- Правый стик — Invert X / Invert Y

Настройка сохраняется и применяется везде (движение, камера, курсор, меню). Кнопка показывается только в режиме геймпада.

Там же настраиваются **свап стрейф/поворот**, **чувствительность поворота** и **вибрация**.

## Вибрация

В **GamePad Setup** каждое событие имеет отдельный тумблер (по умолчанию все включены):

- Получение урона — короткий вибро
- Убийство моба/игрока — обычный вибро
- Получение base/job уровня — длинный вибро
- Подтверждение действия в меню — лёгкий тик
- Смерть персонажа — двойной тик
- Критический удар своей атакой — одинарный тик

## ESC-меню

Кнопка **Start (≡)** в любом режиме открывает/закрывает ESC-меню. В разделе Help крестовина вверх/вниз прокручивает страницу.
