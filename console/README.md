# `console/` — консольные слоты (изолированы от сборки)

Скелеты консольных бэкендов и общих сервисов. **Ни один файл здесь не включён в
CMake-таргеты** — как и `../uwp/`, это заготовки, чтобы после покупки лицензий порт
вставлялся в готовые слоты. Десктоп/Android/arm сборки это не трогает.

> ⚠️ **Никакого проприетарного SDK.** Здесь только наши интерфейсы и заглушки.
> Официальный SDK вендора подставляет лицензированный разработчик в местах,
> помеченных `// TODO(SDK):`. Полный план — [../docs/console-port-plan-km.md](../docs/console-port-plan-km.md).

## Содержимое

- `../src/platform/ConsoleServices.hpp` (+ `.cpp`) — интерфейс сверх десктопного
  `Platform`: жизненный цикл (suspend/resume), storage сейвов (контейнеры),
  пользователь/аккаунт. Уже **в сборке**: десктоп использует файловую no-op реализацию
  `DesktopConsoleServices`, доступ через `consoleServices()`; консольный бэкенд ставит
  свою через `setConsoleServices()`.
- `reference/` — референс-скелет платформенного бэкенда (Platform/Window/Input) с
  TODO-метками, где подставляется SDK. Копируется в `console/<vendor>/` и заполняется.

## Слоты по вендорам (создаются при работе над портом)

- Xbox (GDK/UWP) → уже `../uwp/` (D3D12, Windows.Gaming.Input, XGameSave/XUser).
- PlayStation 5 → `console/prospero/` (bgfx AGC/GNM под NDA, pad/save/user API).
- Nintendo Switch → `console/nx/` (bgfx NVN под NDA, hid, account/fs save-data).

Как только слот заполнен реальным SDK-кодом — он остаётся ПРИВАТНЫМ (NDA), в публичную
часть репо не пушится; сюда коммитим только чистые интерфейсы/заглушки.
