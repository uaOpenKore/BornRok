# Server → client packet coverage (PACKETVER 7)

A checklist of which `ZC_*` (map-server → client) packets the client handles vs. doesn't,
so the gaps can be worked off deliberately. Generated by auditing `src/map/clif.c`
opcode writes against `Client/src/net/Protocol.hpp` (the `PKT_ZC_*` enum) +
`Client/src/game/GameScene.cpp` (the dispatch switch).

**Tally:** the PV7 server sends **238** distinct client-facing opcodes — **78 handled**,
**~159 not handled**. (Mercenary + quest-log packets are PV > 7 → not sent here, so no gap.)

> Status keys: ✅ handled · ⬜ TODO · 🔥 high-frequency (absence visible immediately)

## Fix first — frequently sent, currently ignored

These broadcast on routine events, so their absence is the most noticeable:

- ✅ `0x79` **newentry/spawn** — a non-PC unit popping into view. *(fixed: 29166221)*
- ⬜🔥 `0x9c` **changed_dir** — a unit turns in place; without it sprites never re-face.
- ⬜🔥 `0x13e` **skillcasting** + `0x1b9` **skillcastcancel** — the cast bar (start / interrupt).
- ⬜🔥 `0x13d` **heal** — HP/SP recovery "+N" float (heals, regen ticks).
- ⬜🔥 `0x110` **skill_fail** — "no SP / on delay / failed" feedback.
- ⬜🔥 `0xc0` **emotion** — emoticon bubble over a unit.
- ⬜🔥 `0x115` **skill_damage2** — skill damage *with knockback* (sibling of the handled `0x1de`).
- ⬜🔥 `0x97` **wis_message** — incoming whisper (PM); `0x98` whisper result.
- ⬜🔥 `0x106` **party_hp** / `0x107` **party_xy** — party HP bars + minimap dots.
