# uaRO Client — v3 (start) «Ground mesh builder» — Design Spec

- **Дата:** 2026-06-21
- **Ветка:** `client/foundation`
- **Подпроект:** v3 — рендеринг (первый шаг: геометрия земли)

## 1. Цель

Превратить распарсенный **GND** в треугольный меш, готовый для загрузки в bgfx:
вершины (позиция, нормаль, UV, цвет) + индексы, сгруппированные по текстурам.
Это геометрический мост между слоем данных (v1/v2) и собственно рендером.
Только геометрия — пиксели текстур берутся из BMP по именам `gnd.textures()` и
загружаются рендером отдельно.

Модуль **`world/GroundMesh`** в новой библиотеке **`client_world`** (зависит от
`core` + `formats`, не от SDL/bgfx) → собирается и тестируется offline.

## 2. Построение

Для каждой ячейки GND (кубик с 4 высотами углов и индексами граней top/front/right):
- **top** (`tileUp >= 0`): горизонтальный квад по 4 углам ячейки на их высотах;
- **front** (`tileFront >= 0`): вертикальная «стена» к соседней ячейке по +y;
- **right** (`tileRight >= 0`): вертикальная «стена» к соседней ячейке по +x.

Для каждой грани берётся поверхность (`GndSurface`): её UV четырёх углов, `textureId`,
вершинный цвет (BGRA → `0xAABBGGRR`). Нормаль считается на грань. Квады
сортируются по `textureId`, после чего пишутся в единый буфер вершин/индексов с
массивом батчей `{textureId, indexStart, indexCount}` — рендер биндит каждую
текстуру один раз. Координата ячейки масштабируется `kTile` (настраивается).

## 3. Проверка

- Юнит-тест (offline): GND 1×1 с одним top-тайлом → 4 вершины, 6 индексов, 1 батч;
  проверка позиций углов, UV, цвета, индексов треугольников.
- **Валидация на реальных данных** (`tools/formatcheck`): для ВСЕХ **921** GND из
  `data.grf` меш строится без сбоев. Образец: `06guild_r` 100×100 → 17 400 вершин,
  26 100 индексов, 4 тексту-батча. Суммарно ~68,4 млн вершин по всем картам.

## 4. Дальше

Загрузка текстур (BMP) в bgfx, рендер меша земли через `render/` (нужен GPU-путь,
проверяемый на dev-машине), затем размещение моделей RSM по данным RSW, спрайты.
