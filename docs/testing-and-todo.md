# Чек-лист тестирования + что ещё не реализовано

Снимок состояния клиента: что тестировать и чего ещё не хватает. Весь видимый текст в клиенте —
**на английском** (доки — на русском). Юнит-тесты ядра: **154 проходят**. Слой приложения/рендера
офлайн собрать нельзя, поэтому визуальные пункты ниже проверяются на пересборке у Сергея.

Всё — в ветке `client/foundation` (основная). *Обновлено 2026-06-28.*

---

## Чек-лист тестирования

**Скиллы / бой**
- [ ] Эффекты `.str` по id скилла (provoke, sonic blow, pierce, bowling, brandish, gloria, kyrie,
      impositio, suffragium, aspersio, benedictio, angelus, magnificat, cure, stormgust, meteor,
      firewall, sanctuary, quagmire, …) — на цели / клетке.
- [ ] Хил: AL_HEAL — зелёное число; Hide / Angelus / бафы не показывают ложное число.
- [ ] Подход на дистанцию: Bash / Sonic Blow / радиусные мага — чар доходит, потом кастует.
- [ ] Искра попадания (`hit.str`) на каждом наносящем урон ударе, синхронно с числом.
- [ ] Курсор: баф держит курсор на мыши (прилипает только к союзнику); нет магнетизма к мобу за
      окном; **без скилла нет прилипания к чарам** (вендинги в городе кликаются).
- [ ] Hide / Cloak: ~45% прозрачность + чип в строке статусов. Стат-бафы поднимают стат в Alt+A.
- [ ] Частицы: Magnum Break — оранжевый бёрст; Grimtooth — коричневые осколки.
- [ ] **Полоса каста** (`0x13e`/`0x1b9`): под кастующим юнитом, заполняется за время каста.

**Пакеты от сервера**
- [ ] `0x79` спаун-в-зону · `0x9c` поворот на месте · `0x13d` восстановление HP/SP (зелёное/синее) ·
      `0xc0` эмоция над юнитом ~2с · `0x110` «Skill failed: …» в чат.

**Вендинг**
- [ ] Плашка: белая подложка, тёмный текст, отступы, перенос на 2 строки если >20 символов.
- [ ] ПКМ по предмету → инфо-окно: описание + «Slots (N) - cards» (иконка+имя карты).

**Гильдия**
- [ ] Логотип гильдии рисуется ПЕРЕД названием над чаром (распаковка zlib-эмблемы). ✅ подтверждено.

**Социалка — ПКМ по чужому игроку**
- [ ] Меню (англ., как на референсе): **Request a deal / Open 1:1 Chat / Register as a Friend /
      Reject Whispering**. Меню не таргетит клетку, закрывается по выбору/мимо/Esc.
- [ ] Request a deal → цель получает запрос обмена. Register as a Friend → запрос в друзья.
      Reject Whispering → блок шёпота. Open 1:1 Chat → подставляет шёпот.
- [ ] `/w <name> <text>` (и пункт чата) → приватка уходит, эхо `[to X]`, ошибки из `0x98`
      (offline / ignoring / not delivered) в чат.

**Окно обмена (#77)**
- [ ] Входящий запрос → диалог **Accept / Decline**. На дистанции 5 клеток.
- [ ] Две корзины (слева я / справа партнёр), наполнение в реалтайме; серая полоса посередине.
- [ ] Положить предмет: **двойной клик** ИЛИ **драг-н-дроп** из инвентаря; стакуемые спрашивают
      количество; своя зени — клик по «send yours» (то же окно ввода).
- [ ] **OK** = замок; **trade** активна только когда оба нажали OK; оба trade → сделка.
      **cancel** закрывает окно сразу.

**Чат (#75)**
- [ ] Лёгкий фон под текстом; 31 строка; скролл колесом + ползунок при переполнении.
- [ ] Перенос строк по словам; белый текст с чёрной обводкой.
- [ ] Нижняя полоса: [to — поле шёпота] [сообщение] [свернуть]; в свёрнутом — кнопка Chat слева внизу.
- [ ] **Под текстовой зоной работает таргет** мобов/чаров/клеток; блокирует только полоса ввода.
- [ ] `/help` `/h` `/h1` `/h2` `/h3` печатают список команд (не уходят в паблик).

**Окна / прочее**
- [ ] Клик по крестику закрытия окна НЕ проваливается в клик по земле.
- [ ] Весь текст в клиенте — на английском (нет русского).
- [ ] MSVC: сборка без варнингов (GCC/Clang и так чисто).

**Диагностика gr2** — у стражей WoE / Эмпериума / дракона / сундуков / флагов консоль пишет
`[WRN] .gr2 model '<file>' (view N) at <map> cell (x,y) NOT rendered` — раз на проп.

## Осталось / в очереди

**В работе по чату (#75)** — раскраска сообщений (сервер салатовый, игроки голубые) + выпадающий
селект истории шептавшихся в нижней полосе.

**#76 Автоатака** (спека есть) — панель справа снизу: Auto HP / Auto SP / Filter / AutoAttack;
фильтр типов мобов (имя+lvl, чекбоксы, ALL/N); автоатака бьёт ближайшего по фильтру; Auto HP/SP —
корзинка под итемы + порог % (дефолт 50, юз с задержкой 0.5с); всё в конфиг чара.

**#78 Соц-системы** — окно/список **друзей** (запрос уже шлётся), **пати** (`0xfa…0x1e9`, HP-бары,
точки на миникарте), окно **гильдии** (~26 опкодов; эмблема уже есть), **чат-комнаты**.

**#79 Гомункул** (окно + скиллы); **аренда/мерки** (зависит от серверной части).

**Заблокировано**
- **#72 серая иконка скилла на откате** — сервер (PV7) НЕ шлёт пакет отката (`0x43d`/postdelay),
  нужна клиентская таблица задержек скиллов — решение за владельцем.
- **#31 рендер моделей gr2** — нужен репак контента `.gr2` Oodle0→Oodle1 (**#71**, контент-менеджер).

**Контент / рендер**
- #32 эффекты RSW-карты (огонь факелов, лепестки сакуры) · #63 затухание мешей между камерой и чаром
  · #69 окно покупки у игрока-вендора · #70 спрайт сокола (контент) · #71 .gr2 → Oodle1 (контент).
- Спрайтовые эффекты состояний (отравление/заморозка/окаменение/стан/сон) — нужен цвет в шейдере.
- Реальные `w_magnum.str` / шипы Grimtooth — нет в GRF (контент); пока частицы.

**Пакеты не обработаны** (полный список: `Client/docs/packet-coverage.md`)
- `0x115` урон с отбросом · `0x1f3` спецэффект на юните · `0x144` метки миникарты · `0x1b3` NPC-cutin
  · `0x81` причина дисконнекта · предметы: опознание / карты / рефайн / крафт / ремонт.
