# Client/content — папка бандл-контента

Сюда кладутся **zip/grf паки игровых данных**, которые сборка «запекает» в пакеты для
платформ, где патчер недоступен или не нужен: **Steam/SteamOS, Switch, PS4/PS5, Xbox**.

## Что класть

Любые паки данных: `data.zip`, `gro.zip`, `palette.zip`, `texture_x4.zip`, `model.zip`,
`BGM.zip`, `UaRO.grf` и т.п. Можно также положить:
- папку `data/` — «свободные» файлы (мажорят паки),
- `data.ini` — если нужен явный список GRF.

## Как это работает

1. **Сборка** (`scripts/build-steam.sh` и будущие консольные скрипты) копирует всё из
   `Client/content/` в подпапку `content/` рядом с бинарником пакета.
2. **Клиент** при старте монтирует **все** `*.zip`/`*.grf` из `content/` рядом с
   бинарником (скан по имени-независимо, Application.cpp `mountGameData`). Патчер при этом
   не нужен — данные уже внутри пакета.
3. Живой ивент-контент (из записываемого кэша платформы) монтируется ПОВЕРХ запечённого,
   так что ивенты переопределяют базу.

На десктопе (Steam-депо без Steamworks) можно оставить папку пустой — тогда контент
докачает встроенный патчер при первом запуске. Для консолей — паки обязательны здесь.

## Git

Сами zip/grf **не коммитятся** (большие бинарники, см. `.gitignore`) — держи их локально.
Коммитится только этот README и `.gitkeep`.
