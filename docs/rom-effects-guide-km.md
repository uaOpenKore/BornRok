# RoM-эффекты навыков (#132) — руководство контент-менеджера

Клиент умеет проигрывать эффекты навыков из RoM (Unity `ParticleSystem`),
привязывая их к номерам навыков Ragnarok. Движок частиц берёт из эффекта
цвет, размер, время жизни, скорость и гравитацию — и рисует их нашими
частицами. Точную текстуру эффекта мы НЕ достаём (она лежит в 23 000+
отдельных бандров за хэш-ссылками — резолвить в реальном времени неоправданно
дорого); вместо неё используется мягкое свечение в цвете эффекта. На практике
эффект получается узнаваемым: магнум — оранжевый, колдболт/фростдайвер — синие,
санктуарий — золотой, напалм — тёмно-призрачный.

## Как это работает

1. При каст навыка сервер шлёт пакет с номером навыка (`skillId`).
2. Клиент ищет `skillId` в таблице привязок.
3. Если привязка есть — грузит бандл `Android/resources/public/effect/skill/<имя>.unity3d`,
   разбирает `ParticleSystem` и проигрывает эффект в точке цели.
4. Если привязки нет — работает как раньше (`.str`-эффект или встроенная анимация).

## Как добавить/поменять привязку

Рядом с исполняемым файлом клиента лежит текстовый файл **`rom-skill-effects.txt`**.
Формат строки:

```
<skillId> = <имя_эффекта_без_расширения>
```

- `skillId` — номер навыка Ragnarok (например `19` для Firebolt).
- `имя_эффекта` — имя файла в архиве без `.unity3d`. Ищите его в
  `Android/resources/public/effect/skill/`. Суффиксы `_lod1`/`_lod2` НЕ берите —
  это упрощённые копии.
- Строки с `#` — комментарии.

Файл **дополняет** встроенную таблицу и переопределяет её при совпадении номера.
Изменения подхватываются при следующем входе на карту.

### Пример

Файл `12_cannon_attack.unity3d` → имя эффекта `12_cannon_attack`.
Чтобы навесить его на условный навык 2510:

```
2510 = 12_cannon_attack
```

## Просмотр и подбор эффектов в игре (команда /fx)

Чтобы не гадать имена и сразу видеть, как эффект выглядит, есть внутриигровые команды (вводятся в чат):

- `/fx list <кусок_имени>` — найти имена эффектов. Например `/fx list fire` выведет
  список подходящих бандлов из `effect/skill/` (до 60 штук).
- `/fx <имя>` — проиграть эффект у себя под ногами. Имя — без `.unity3d` и без `_lod`.

Так удобно перебирать эффекты и подбирать, какой навесить на навык (потом впиши пару
`skillId = имя` в `rom-skill-effects.txt`).

## Технические заметки (для разработчика)

- Парсер: `Client/src/formats/UnityParticle.{hpp,cpp}`. Раскладка `ParticleSystem`
  (класс 198) для Unity 2021.3 взята из uTinyRipper. Тип-дерево в RoM вырезано,
  поэтому поля читаются позиционно; преамбула переменной длины (в `StartDelay`
  лежит список кейфреймов), поэтому `InitialModule` находится сканированием по
  диапазонам валидных значений. Оффлайн-проверка: ~89% эффектов навыков парсятся.
- Рантайм: `GameScene::loadSkillFxBindings / loadRomFxDesc / emitRomEffect /
  updateRomFx`. Частицы льются в тот же пул `skillParticles_`, что и встроенные
  эффекты, и рисуются `drawSkillParticles` (аддитивные билборды).
