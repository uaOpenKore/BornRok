# uaRO Client — v2 «Map formats: GAT / GND / RSW» — Design Spec

- **Дата:** 2026-06-21
- **Ветка:** `client/foundation`
- **Подпроект:** v2 — форматы ассетов (карты)

## 1. Цель

Парсеры трёх форматов, которые вместе задают карту RO. Все читают байтовый буфер
из `Vfs`, отдают структуры данных; рендер карты — позже (v3).

- **GAT** (Ground Altitude Table) — сетка проходимости/высот по ячейкам.
- **GND** (Ground) — текстурированный мешь земли.
- **RSW** (Resource World) — определение мира: какие GND/GAT грузить, вода, свет,
  и список размещённых объектов (модели/звуки/эффекты).

Все три — в `client_formats` (зависит только от `core`) → собираются и тестируются
offline.

## 2. Форматы (раскладки подтверждены реверсом реальных файлов)

**GAT** (магия `GRAT`, версия 1.2): width/height (u32), затем width×height ячеек
по 20 байт — 4 float (высоты углов) + u32 (тип/проходимость).

**GND** (магия `GRGN`, версия 1.7): width/height (u32), zoom (float), список текстур
(count + nameLen + имена по nameLen байт), лайтмапы (v≥1.7: count + 8×8 + skip
count·8·8·4 байт пиксельных данных), поверхности (count × 40 байт: u[4],v[4] float,
textureId i16, lightmapId i16, color BGRA), кубы (width×height × 28 байт: 4 float
высоты + 3 i32 индекса граней).

**RSW** (магия `GRSW`, версия 2.1): 4 имени файла по 40 байт (ini/gnd/gat/scr),
вода (level/type/waveHeight/waveSpeed/wavePitch + animSpeed при v≥1.8), свет
(longitude/latitude i32 + diffuse[3]/ambient[3]/opacity float), ground bounding box
(4 i32), затем `objectCount` и список объектов. Парсятся **объекты-модели** (type 1):
name[40], animType, animSpeed, blockType, filename[80] (.rsm), nodeName[80],
pos/rot/scale — размещения RSM на карте (248 байт). **Объём:** на первом объекте
НЕ-модель (свет/звук/эффект) разбор объектов останавливается — их раскладки сильно
version-зависимы (по реальным данным видна несогласованность смещений), поэтому
реверсятся отдельным инкрементом. `complete()` сообщает, все ли объекты были
моделями. За списком объектов идёт quad-tree (пока не парсится — нормальный «хвост»).

## 3. Робастность

Все парсеры отвергают неправдоподобные размеры/счётчики до аллокаций (защита от
битых/враждебных файлов) и возвращают `nullopt` вместо падения.

## 4. Проверка

- Юнит-тесты (offline): синтетические GAT/GND/RSW round-trip.
- **Валидация на реальных данных** (`tools/formatcheck` против настоящего
  `data.grf`): **GAT 924/0, GND 921/0, RSW 924/0** — 0 ошибок. RSW извлекает
  размещения моделей на всех 924 картах без рассинхрона (55 карт — чисто модельные;
  на остальных берутся ведущие модели до первого не-модельного объекта). Образец
  подтверждает корректные имена (`*.gnd`/`*.gat`), воду и свет.
