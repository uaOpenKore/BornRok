# Анализ оригинального клиента (Ragexe) — эффекты / звук / форматы

Источник: `Ragexe.exe` (14.6 МБ, PE32, **не упакован**) + лаунчер `Ragnarok.exe` (4.5 МБ, только запуск).
Разбор строк/секций/импортов. Цель — понять, что умеет оригинал, и подтянуть наш клиент.

## 1. Эффекты (.str)

- Оригинал ссылается на **1288 уникальных `.str`** (у нас в `effectFxStr` — 208 имён, совпадает 188).
  → **~1100 новых эффектов**, в основном 4th-job: `abyss_slayer*`, `abyss_strike*`, `acidified_zone_*`,
  `a_machine_*`, и т.д. Полный список имён — `ragexe_str_names.txt` (в scratchpad).
- Диспетчер — по-прежнему **switch `CEffect::Initialize`** (массива указателей на .str НЕТ, проверено
  сканом всего exe). Значит точный **EFFECTID→.str** снимается только дизассемблом switch.
- **Важно:** имя `.str` ≠ имя `EF_`-константы сервера в большинстве случаев, и нумерация клиентского
  EFFECTID ≠ `db/const.txt` (сверка id по имени дала лишь 3 совпадения). Т.е. кросс-мап по именам НЕ
  работает — нужен именно дизассембл клиентского switch (как для старого exe → 166 пар).
- 25 `%d`-мультикадровых семейств (у нас загрузчик на 8 уже есть, коммит 4f9b9966).

## 2. Звук

- Движок оригинала — **Miles Sound System** (`mss32.dll`) — проприетарный, только Windows. Мы его НЕ
  используем (перешли на SDL3 core + dr_libs, #103) — и правильно, Miles кросс-платформенно мёртв.
- Ассеты переиспользуемы (это главное):
  - **SFX:** `data\wav\effect\*.wav` — эффекты (`storm.wav`, `EF_Blessing.wav`, `drop_red/green/blue.wav`),
    хиты (`effect\EF_hit2.wav`, `EF_hit4.wav`), ловушки (`WH_*_TRAP_HIT.wav`).
  - **Мобы:** пер-моб `<name>_attack.wav` / `<name>_hit.wav` (`wolf_attack.wav`, `spore_attack.wav`,
    `ice_titan_attack.wav`).
  - **BGM:** `bgm\%s.mp3`, карта→трек через `mp3NameTable.txt`.
- Т.е. таблицы **эффект→wav / моб→attack|hit wav / скилл→wav** извлекаемы из exe (та же зона, что и .str).

## 3. Видео

- **Bink** (`binkw32.dll`, `BinkOpen/Wait/Close`) — интро-ролик `openning.bik`. У нас нет (мелочь).

## 4. Форматы (что грузит оригинал)

| Категория | Форматы | У нас |
|---|---|---|
| 2D-спрайты | `.spr` `.act` `.pal` | ✅ есть |
| 3D-модели карт | `.rsm` | ✅ есть |
| 3D-мобы (Granny) | `.gr2` (`model\3dmob\`, `3dmob_bone\%d_%s.gr2`, guildflag) | ⚠️ парсер есть (feat/gr2), блокер Oodle (#71/#113) |
| Карты | `.gat` `.gnd` `.rsw` | ✅ есть |
| Видео | `.bik` (Bink) | ❌ нет (интро) |
| Текстуры | `.bmp` `.tga` `.pal` | ✅ есть |

## 5. Вывод — что делать, чтобы «как оригинал»

1. **Эффекты (главный разрыв, 208→1288):** дизассемблировать `CEffect::Initialize` в Ragexe →
   полный EFFECTID→.str, влить в `effectFxStr`. Контент (.str) в основном есть в GRO.grf/data.grf.
   Это самый большой прирост «похожести».
2. **Звук:** извлечь таблицы эффект→wav / моб-attack/hit / скилл→wav из exe и подключить к нашим
   SDL3-хукам (BGM через mp3NameTable уже есть). Расширяет #103.
3. **Форматы:** почти всё уже поддержано; остаётся gr2 (блокер Oodle, отдельная линия) и Bink-интро
   (низкий приоритет).

Приоритет по влиянию: **эффекты → звук-таблицы → (gr2/видео опционально)**.

## 6. Детали по пунктам (после разбора)

**Эффекты (сделано, aac7f532):** switch размотан — `jmp [eax*4+0x6d37ec]`, EFFECTID=idx+13,
380 id→.str (`docs/ragexe-effect-map.md`). Влито 14 (те, чей .str есть в нашем GRF). Остальные
**342** — контент отсутствует у нас (`docs/ragexe-effects-missing-content.md`).

**Звук:** таблицы НЕТ — звук по соглашению имён (`<эффект>.wav`, `<моб>_attack/_hit/_die.wav`,
`_attack_<оружие>.wav`, `<эффект>_cast.wav`). Наш #103 это уже делает. Мелкие пробелы: звук атаки
самого моба + каст-звук скилла.

**gr2 (пункт 3):** оригинал линкует **RAD Granny SDK статически** (`C3dGrannyModelRes/GameActor/
Pc/Corpse3d`, `GrannyPNT332VertexType`), рендер **DirectX 9** (`d3d9.dll`+`d3dx9_43.dll`, `DDRAW`),
`model\3dmob\%s` + `model\3dmob_bone\%d_%s.gr2`. **Oodle в этом клиенте НЕ используется** (только
zlib 1.2.13) — значит наш блокер #71 (Oodle mis-decode) под вопросом: модерн-gr2, вероятно, в
стандартном Granny/zlib, а не Oodle. Чтобы дополнить gr2 «как оригинал» — нужны **сами .gr2 из
GRF модерн-клиента** (у нас их нет). Тот же GRF разблокирует и 342 эффекта → **главный запрос к
Sergio: дать GRF/контент модерн-клиента.**
