# Кнопки геймпадов: Xbox / PlayStation 5 / Nintendo Switch

> Справочник для портов на консоли (#99). Наш клиент на SDL3, поэтому ввод геймпада идёт
> через единый слой **SDL_Gamepad** (`SDL_GamepadButton` / `SDL_GamepadAxis`): мы пишем код
> против SDL-имён, а SDL сам мапит их на физические кнопки каждой платформы. SDL3 называет
> лицевые кнопки **позиционно** (South/East/West/North), а не A/B/X/Y — потому что у Nintendo
> A/B и X/Y расположены зеркально к Xbox. Таблица ниже даёт соответствие SDL → физическая кнопка.

## Главная таблица соответствия

| SDL3 (`SDL_GAMEPAD_BUTTON_*`) | Позиция | Xbox | PlayStation 5 | Nintendo Switch |
|---|---|---|---|---|
| `SOUTH` | низ | **A** | **✕** Cross | **B** |
| `EAST` | право | **B** | **○** Circle | **A** |
| `WEST` | лево | **X** | **▢** Square | **Y** |
| `NORTH` | верх | **Y** | **△** Triangle | **X** |
| `LEFT_SHOULDER` | бампер L | **LB** | **L1** | **L** |
| `RIGHT_SHOULDER` | бампер R | **RB** | **R1** | **R** |
| `LEFT_STICK` | нажатие L-стика | **LS (L3)** | **L3** | **нажатие L-стика** |
| `RIGHT_STICK` | нажатие R-стика | **RS (R3)** | **R3** | **нажатие R-стика** |
| `DPAD_UP/DOWN/LEFT/RIGHT` | крестовина | **D-Pad** | **D-Pad** | **D-Pad / стрелки** |
| `START` | меню/старт | **Menu** ☰ | **Options** | **Plus** ＋ |
| `BACK` | вид/назад | **View** ⧉ | **Create** | **Minus** − |
| `GUIDE` | системная | **Xbox (Nexus)** | **PS** | **Home** |
| `MISC1` | доп. системная | **Share** (Series) | **Mute** (микрофон) | **Capture** (скриншот) |
| `TOUCHPAD` | клик тачпада | — | **клик тачпада** | — |
| `RIGHT_PADDLE1` / `LEFT_PADDLE1` | задние лепестки | **Elite P1/P3** | задние кнопки (Edge/накладки) | — |
| `RIGHT_PADDLE2` / `LEFT_PADDLE2` | задние лепестки | **Elite P2/P4** | задние кнопки (Edge/накладки) | — |

## Оси (`SDL_GamepadAxis`, аналоговые)

| SDL3 (`SDL_GAMEPAD_AXIS_*`) | Xbox | PlayStation 5 | Nintendo Switch |
|---|---|---|---|
| `LEFTX` / `LEFTY` | левый стик | левый стик | левый стик |
| `RIGHTX` / `RIGHTY` | правый стик | правый стик | правый стик |
| `LEFT_TRIGGER` | **LT** (аналог.) | **L2** (аналог.) | **ZL** (цифровой) |
| `RIGHT_TRIGGER` | **RT** (аналог.) | **R2** (аналог.) | **ZR** (цифровой) |

Примечание: триггеры на Xbox/PS5 — аналоговые (0..1), на Switch (Pro Controller / Joy-Con)
ZL/ZR **цифровые** (только вкл/выкл), SDL отдаёт их как ось с двумя крайними значениями.

## Полный список физических кнопок по платформам

**Xbox (Series X|S / One / Elite):**
- Лицевые: A, B, X, Y
- Бамперы: LB, RB · Триггеры: LT, RT (аналог.)
- Стики: левый/правый + нажатие (LS/RS) · D-Pad (8 направлений)
- Системные: Menu (☰), View (⧉), Xbox/Nexus (Guide), **Share** (Series)
- Elite: 4 задних лепестка (P1–P4), профильный переключатель

**PlayStation 5 (DualSense / DualSense Edge):**
- Лицевые: ✕ Cross, ○ Circle, ▢ Square, △ Triangle
- Бамперы: L1, R1 · Триггеры: L2, R2 (аналоговые, с адаптивным сопротивлением)
- Стики: левый/правый + нажатие (L3/R3) · D-Pad
- Системные: Options, Create, **PS** (Guide), **Mute/микрофон** (MISC1)
- **Тачпад**: клик (кнопка) + сенсорная поверхность (2 касания)
- Доп. фишки DualSense (не как кнопки): гироскоп, адаптивные триггеры, хаптика
- Edge: 2 задних кнопки/лепестка (переназначаемые)

**Nintendo Switch (Pro Controller / Joy-Con пара):**
- Лицевые: A, B, X, Y (расположение A/B и X/Y зеркально к Xbox)
- Плечевые: L, R · Триггеры: ZL, ZR (цифровые)
- Стики: левый/правый + нажатие · D-Pad (на Joy-Con — 4 отдельные кнопки)
- Системные: Plus (＋), Minus (−), **Home**, **Capture** (скриншот, MISC1)
- Joy-Con в раздельном режиме: дополнительно **SL / SR** на каждом контроллере
- Доп.: гироскоп, HD-вибрация, ИК-камера (правый Joy-Con)

## Практика для нашего клиента

- Кодить против **SDL-имён** (`SOUTH`/`EAST`/…/`DPAD_*`/`*_TRIGGER`), не против A/B/X/Y —
  тогда одна раскладка работает на всех трёх консолях, а подписи в UI подставлять по
  платформе из таблицы выше (`SDL_GetGamepadType()` различает Xbox/PS/Switch).
- RO заточен под мышь: для геймпада нужен курсор-режим (левый стик двигает курсор, `SOUTH` =
  ЛКМ-клик, `EAST` = ПКМ/отмена) либо прямое нацеливание на ближайшую цель — это основная
  работа порта (см. [port-audit.md](port-audit.md)).
- Подсказки кнопок в интерфейсе показывать значками платформы (✕/○ для PS, A/B для Xbox,
  A/B Nintendo) — SDL даёт тип контроллера, остальное из этой таблицы.
