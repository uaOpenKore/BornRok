# uaRO Client — v3 «Map loader» — Design Spec

- **Дата:** 2026-06-21
- **Ветка:** `client/foundation`
- **Подпроект:** v3 — рендеринг (сборка данных карты)

## 1. Цель

`MapLoader::load(Vfs&, mapName)` собирает ВСЕ CPU-данные одной карты через VFS —
капстоун, связывающий весь конвейер ассетов (v1/v2) воедино. Результат `MapData`
готов к загрузке в GPU рендером (следующий шаг, нужна dev-машина).

## 2. Что собирается (`MapData`)

1. `data/<name>.rsw` → `Rsw` (мир: вода, свет, размещения моделей).
2. `data/<rsw.gndFile>` → `Gnd`; `data/<rsw.gatFile>` → `Gat`.
3. `GroundMesh::build(gnd)` → геометрия земли.
4. Текстуры земли: для каждой `gnd.textures()` — `data/texture/<name>` → `Bmp::decode`
   (→ RGBA `Image`).
5. Модели: для каждого `rsw.models()` — `data/model/<filename>` → `Rsm::parse`,
   с дедупликацией по имени файла (`rsmCache` + `placements` со ссылкой-индексом).

Модуль `world/MapLoader` в `client_world`; добавляется только при наличии
resource/VFS (zlib).

## 3. Проверка

- Юнит-тесты компонентов (GroundMesh, все парсеры/декодеры) — offline, зелёные.
- **Сквозная проверка на реальных данных** (`tools/maptest <grf> <map>`): загрузка
  настоящих карт из `data.grf` целиком, без GPU:
  - **prontera** 156×196: меш 114 044 верш. / 13 батчей, текстуры 13/13,
    размещения 1276/1276 (55 уник. моделей);
  - **izlude** 134×134: меш 68 968 верш., текстуры 26/26, размещения 644/644;
  - **06guild_r** 100×100: меш 17 400 верш., текстуры 4/4, размещения 16/16.

Весь путь GRF → VFS → RSW → GND/GAT → меш → текстуры → модели работает на реальных
данных.

## 4. Дальше (нужна dev-машина с GPU)

Загрузка `MapData` в bgfx (вершинные/индексные буферы + текстуры), рендер меша
земли и моделей RSM по размещениям, камера, свет из RSW. Это первый визуальный
результат — проверяется только на машине с дисплеем.
