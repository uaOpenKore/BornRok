# Кодовые эффекты скиллов (реверс из uaRO.exe)

Часть скилл-эффектов в оригинале — **не .str и не .spr, а процедурные**: клиент создаёт
эффект-объект (фабрика `0x5c3670`, ~63КБ, система частиц: 50 эмиттеров × 512 частиц) и настраивает
его РЕАЛЬНЫМИ текстурами `.tga` из `data\texture\effect\`, которые он рисует как расширяющиеся/гаснущие
биллборды. Это и есть источник, который надо воспроизводить (не выдумывать).

## Как извлечено

Для каждого скилла ищем строку звука `effect\EF_<Skill>.wav`, находим её xref (push imm32) —
это код эффект-хендлера, — и дизассемблируем участок ПОСЛЕ вызова фабрики `0x5c3670`: там
пушатся реальные имена `.tga`/`.spr` + float-параметры (радиус, scale). Скрипт скрейпа —
walk по строкам `EF_*.wav` → xref → `.tga/.spr/.str` в окне хендлера.

## Воспроизведение

`.tga`-эффекты (кольца/вспышки) собираются синтетическим `Str` (`buildCodedFx` в GameScene.cpp):
аддитивный биллборд, растёт start→end px, альфа гаснет 1→0. Играется через рабочий StrEffect-рендер.
Реализованы: **Magnum (7)**, **Bash (5)**, **Stone Curse (16)** (commit-ы 8158402e + далее).

`.spr`-эффекты (Thunder Storm `썬더스톰.spr`, Aqua `성수뜨기.spr`) — это спрайт-анимации, играются
через CharacterActor (как fireball у Fire Ball), TODO.

**Правило:** ассеты берём ТОЛЬКО из этой таблицы (реальный EXE), размеры/скорость подстраиваем
по картинке в игре. Ничего не выдумывать.
