# Пути спрайтов/анимаций (из оригинального uaRO.exe)

> Источник: дизассемблирование `uaRO.exe`. Извлечены **format-строки построения путей**
> (sprintf по адресам ~0x5b1c30 и др.) и литеральные пути. Все пути — от корня `data\`,
> разделитель `\`, кодировка имён — EUC-KR (cp949). `%s`=строка, `%d`=число.

## Главный вывод по «кривым спрайтам»

Алгоритм построения путей в exe **совпадает** с нашим `CharacterActor` (тело
`인간족\몸통\<пол>\<джоб>_<пол>`, голова `인간족\머리통\<пол>\<hairId>_<пол>`). Сами
**имена джобов/оружия/головных уборов в exe НЕ зашиты** — они грузятся в рантайме
(глобальные указатели `*0x771988`/`*0x7719e8`, индекс `job*4`, заполняются из данных, а
не статической таблицей). То есть, как и со скиллами, авторитетный источник имён —
**данные GRF (lua jobname/accname/weapontable)**, а не бинарь. Вывод: путёвый алгоритм у
нас правильный; неправильно отображаемые спрайты = **неверная/отсутствующая запись в
таблицах имён** (`jobSpriteName` / weapon / shield / headgear в `CharacterActor.cpp`),
её надо чинить по конкретному классу.

## Шаблоны путей (подтверждены, EUC-KR + перевод)

Корейские компоненты: `인간족`=раса-человек, `몸통`=тело, `머리통`=голова, `악세사리`=аксессуар
(головной убор), `용병`=наёмник, `몬스터`=монстр, `이팩트`=эффект, `검광`=блик оружия,
`남`=муж, `여`=жен.

| Что | Шаблон (от `data\`) |
|---|---|
| Тело игрока | `sprite\인간족\몸통\<пол>\<джоб>_<пол>.spr` / `.act` |
| Тело + блик оружия | `sprite\인간족\<джоб>_<пол>_<weap>_검광.spr` |
| Голова игрока | `sprite\인간족\머리통\<пол>\<hairId>_<пол>.spr` / `.act` |
| Головной убор | `sprite\악세사리\<пол>\<пол>_<accName>.spr` / `.act` |
| Наёмник | `sprite\인간족\용병\{검용병_검\|창용병_창\|활용병_활}[_검광].spr` (меч/копьё/лук) |
| Монстр | `sprite\몬스터\<name>.spr` / `.act` |
| NPC | `sprite\NPC\<name>.spr` / `.act` |
| Гомункул | `sprite\homun\<name>.spr` / `.act` |
| Тень | `sprite\shadow.spr` |
| Курсор | `sprite\cursors.spr` ; эмоции `sprite\이팩트\emotion.spr` |
| 3D-монстр | `model\3dmob\<name>` ; кости `model\3dmob_bone\<id>_<name>.gr2` |
| Иконка предмета | `유저인터페이스\item\<name>.bmp` |

## Что чинить дальше

Имена джобов нужно сверить с GRF (jobname-таблица). Если нужно системно — могу написать
маленький экстрактор поверх нашего `resource/Grf` и вытащить авторитетные имена
джобов/оружия/уборов прямо из `data.grf`, затем выровнять `CharacterActor.cpp`. Либо точечно
по списку конкретных кривых спрайтов от Сергио.
